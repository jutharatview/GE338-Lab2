# GE338-Lab2
Lab 2 Spatial Analysis กับ Google Earth Engine
พื้นที่ศึกษา อำเภอ เถิน จังหวัด ลำปาง ตั้งอยู่ในบริเวณภาคเหนือของประเทศไทย พื้นที่มีลักษณะเป็นแอ่งกระทะ อุณหภูมิในพื้นที่สูงเกือบทุกปี ปริมาณน้ำฝนน้อย ทำให้แม่น้ำวังและลำห้วยต่างๆแห้งขอด อีกทั้งอำเภอนี้เป็นพื้นที่แล้งซ้ำซาก
คำถาม การศึกษานี้จะช่วงให้อำเภอเถิน แล้งน้อยลงได้หรือไม่ สามารถนำความรู้ในเรื่องนี้ไปปรับใช้ในการแก้ปัญหาภัยแล้งได้อย่างไรบ้าง
ข้อมูลดาวเทียมและเลือกช่วงเวลา
Sentinel-2 เนื่องจากมีความละเอียดสูง 10 เมตร ซึ่งเหมาะกับการวิเคราะห์พื้นที่ในระดับอำเภอ และมี  Band ที่รองรับการคำนวณ Index อย่าง NDVI NDWI
เลือกเป็นช่วงเวลาเดือนกุมภาพันธ์-เมษายน ปี 2020 และ 2024 ซึ่งเป็นช่วงหน้าแล้ง
ตั้งค่าการกรองเมฆ < 20% เพื่อช่วยลดผลกระทบจากเมฆ แต่ยังคงมีจำนวนภาพเพียงพอ
วิเคราะห์และตีความ
1.	คำนวณและแสดงผล Spectral Index ที่เหมาะสมกับพื้นที่ศึกษา 
NDVI ใช้ในการวิเคราะห์ความหนาแน่นของพืชพรรณ โดยค่าที่สูงแสดงถึงพื้นที่ที่มีพืชพรรณหนาแน่น และ NDWI ใช้ในการตรวจสอบความชื้นและแหล่งน้ำ โดยค่าที่สูงแสดงถึงพื้นที่ที่มีน้ำหรือความชื้นสะสม
โดยพบว่า ในพื้นที่ภูเขาและพื้นที่ป่าไม้จะมีค่า NDVI สูง พื้นที่โล่งแห้ง จะมีค่า NDVI ต่ำ และพื้นที่ใกล้แหล่งน้ำหรือมีความชุ่มชื้นจะมีค่า NDWI สูง
2.	เปรียบเทียบ Composite 2 ช่วงเวลาและอธิบายการเปลี่ยนแปลงที่พบ
ได้ทำการ composite 2 ช่วงคือปี 2020 กับ 2024 โดยวิธี median composite เพื่อลดผลกระทบจากเมฆ โดยเมื่อเปรียบเทียบค่า NDVI ในสองปีพบว่า ในบริเวณพื้นที่ภูเขามีสีเขียวเพิ่มากขึ้นในปี 2024 แสดงว่าค่า NDVI เพิ่มมากขึ้นพืชพรรณเพิ่มมากขึ้น แต่ในบางพื้นที่มีสีเขียวอ่อนหรือสีเหลือง ค่า NDVI ลดลง พืชพรรณลดลงหรือแล้ง และวิเคราะห์จาก NDWI พบว่าปี 2020 แสดงค่าสีฟ้าน้ำเงินเข้มมากกว่าปี 2024 บ่งบอกว่าปี 2024 มีสภาพอากาศที่แห้งแล้งมากขึ้น หรือได้รับปริมาณน้ำฝนน้อย
3.	วิเคราะห์ความสัมพันธ์ระหว่าง Index 2 ตัว และ Interpret ผล
NDVI ใช้บอกความสมบูรณ์ของพืชพรรณ ขณะที่ NDWI ใช้บอกปริมาณความชื้นหรือน้ำในพื้นที่  โดยพื้นที่ที่มีพืชพรรณหนาแน่นค่า NDVI สูง ไม่ใช่แหล่งน้ำโดยตรงจึงทำให้ค่า NDWI ต่ำ ในพื้นที่ที่มีค่า NDWI สูง มักเป็นแหล่งน้ำ หรือพื้นที่ชุ่มน้ำซึ่งไม่มีพืชพรรณหนาแน่นส่งผลให้ค่า NDVI ต่ำ โดยในอำเภอเถินพืชพรรณส่วนใหญ่จะอยู่บริเวณป่ามากกว่าที่จะอยู่บริเวณใกล้แหล่งน้ำ จากการวิเคราะห์แสดงให้เห็นว่าในปี 2024 พื้นที่มีความชื้นลดลงเมื่อเทียบกับปี 2020 ความหนาแน่นของพืชพรรณเปลี่ยนแปลงเพียงเล็กน้อย สะท้อนถึงความสามารถในการปรับตัวของพืชในสภาพแห้งแล้ง และแสดงให้เห็นถึงความสัมพันธ์เชิงลบระหว่าง NDVI และ NDWI ในพื้นที่ศึกษา
